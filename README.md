# SPOT WALL — بازار اسپات طلای طلاین

ویدیووال فارسی ۹۶۰×۵۷۶ شامل نمودار کندل واقعی، اوردربوک ۱۵+۱۵ و آمار بازار طلای ۱۸ عیار.

## اجرای محلی

نیازمندی: Node.js نسخه ۲۲.۱۳ یا جدیدتر.

```bash
npm install
export TLYN_SESSION_COOKIE='apptlynir_session=<YOUR_CURRENT_SESSION_VALUE>'
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید. صفحه نسبت ۹۶۰×۵۷۶ را در هر نمایشگر به‌صورت متناسب Scale می‌کند.

متغیر `TLYN_SESSION_COOKIE` فقط در پردازش سرور استفاده می‌شود و هرگز به مرورگر برگردانده نمی‌شود. بدون این متغیر، قیمت عمومی همچنان زنده است و اوردربوک از آخرین ساختار معتبر/سطوح مکمل استفاده می‌کند.

## داده‌ها

- قیمت عمومی: هر ۳ ثانیه از `https://price.tlyn.ir/api/v1/price`
- اوردربوک: از مسیر واسط سرور به `https://my.tlyn.ir/api/v1/orders/data`
- تاریخچه واقعی کندل: `candle-price-chart` با رزولوشن‌های ۱۵ دقیقه، ۲۴۰ دقیقه و روزانه
- کش کندل: `localStorage` مرورگر با نسخه‌بندی و اعتبارسنجی؛ رفرش صفحه تاریخچه را تصادفی بازتولید نمی‌کند.
