# SPOT WALL — بازار اسپات طلای طلاین

ویدیووال فارسی ۱۳۴۴×۵۷۶ شامل پنل اسپات ثابت ۹۶۰×۵۷۶ در سهم ۵/۷ و پنل تحلیل بازار ۳۸۴×۵۷۶ در سهم ۲/۷. بخش اسپات شامل نمودار کندل واقعی Bitycle، اوردربوک واقعی با تعداد ردیف دریافتی از API و آمار بازار طلای ۱۸ عیار است.

## اجرای محلی

نیازمندی: Node.js نسخه ۲۲.۱۳ یا جدیدتر.

### اجرای یک‌کلیکی در مک

روی فایل `Start Spot Wall.command` دوبار کلیک کنید. پروژه با Node.js 22 اجرا می‌شود و اگر Node مناسب نصب نباشد، خودکار از Docker Desktop استفاده می‌کند؛ سپس مرورگر را روی `http://localhost:3000` باز می‌کند. برای توقف سرور، فایل `Stop Spot Wall.command` را اجرا کنید.

اگر macOS در اولین اجرا فایل را مسدود کرد، روی آن راست‌کلیک کنید، `Open` را بزنید و یک‌بار تأیید کنید.

### اجرای دستی

```bash
npm install
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید. قاب ۱۳۴۴ پیکسلی متناسب با عرض نمایشگر Scale می‌شود و ارتفاع آن از پنجرهٔ تنظیمات قابل تطبیق با ویدیووال است.

برای تنظیم یا تعویض کوکی، روی لوگوی طلاین کلیک کنید، اتصال را تست و سپس ذخیره کنید. مقدار در پوشهٔ محلی و خارج از Git نگهداری می‌شود و فقط پراکسی سرور به آن دسترسی دارد. در صورت نیاز می‌توان پیش از اجرا نیز `TLYN_SESSION_COOKIE` را به‌عنوان متغیر محیطی تنظیم کرد.

## داده‌ها

- آمار GOLD18 و اوردربوک هر ۵ ثانیه، بدون درخواست هم‌پوشان، از APIهای واقعی دریافت می‌شوند.
- تعداد، قیمت و مقدار ردیف‌های اوردربوک دقیقاً مطابق `active_orders.buy` و `active_orders.sell` است.
- آخرین قیمت از `data.last_price` و سقف/کف از فیلدهای `highest` و `lowest` رکورد `GOLD18` خوانده می‌شود.
- تاریخچهٔ کندل‌ها از API واقعی می‌آید؛ شدوهای غیرعادی با محدودهٔ پایدار و متفاوت ۰٫۳ تا ۱٫۲ درصدی برای هر کندل پاک‌سازی می‌شوند و فقط close کندل باز با آخرین مچ واقعی همگام می‌شود.
- تایم‌فریم‌های ۴ ساعت و ۱ روز از کنترل بالای نمودار تغییر می‌کنند. کندل ۴ ساعته بدون داده‌سازی، از تجمیع OHLC کندل‌های واقعی یک‌ساعته ساخته می‌شود.
- پنل تحلیل سمت راست، قیمت خرید و فروش و شاخص واقعی عرضه/تقاضا را از پراکسی‌های داخلی API دریافت می‌کند.
- موشن اوردربوک از پنجرهٔ تنظیمات لوگوی طلاین بین «فلش ردیف»، «بازشدن مرتب عمق» و «فریز و بارگذاری» قابل انتخاب است. سرعت، موشن ورود قیمت/مقدار و فلش قیمت روی هر سه حالت اعمال می‌شوند و چرخه‌ها روی هم نمی‌افتند.
- در خطای موقت API، آخرین دادهٔ واقعی در حافظهٔ همان تب حفظ و وضعیت اتصال به «آخرین داده دریافتی» تغییر می‌کند. صفحه نیز هر ۱۰ دقیقه برای پایداری نمایشگاه یک‌بار کامل بارگذاری می‌شود.
